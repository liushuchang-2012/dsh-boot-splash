# dsh-boot-splash · 白鲸化黑启动动画

A startup splash for [DeepSeek Harness](https://github.com/deepseek-ai): the white‑blue whale
sits alone in the middle of the screen, floods **black** from the bottom up in step with the
loading arc, glides left, and pulls the `| deepseek HARNESS` wordmark out behind it.

![boot splash](preview/boot-splash.gif)

中文说明见 [README.zh.md](README.zh.md)。

## What happens (7.6 s, one deterministic timeline)

| time | beat |
| --- | --- |
| 0.0 s | the blue whale condenses out of a soft blue bloom, breathing |
| 0.7 s | a thin loading arc fades in and starts to draw |
| 1.1 s | an ink tide rises through the body; the arc's head rides exactly with it |
| 3.6 s | the whale is fully black, the arc closes, one sonar ripple leaves it |
| 3.8 s | the whale glides left, leaving two afterimage ghosts, and condenses |
| 4.4 s | `deepseek` is pulled out of the whale, glyph by glyph |
| 5.1 s | the black plate slides out of the wordmark and uncovers `HARNESS` |
| 5.6 s | the whole lockup settles with a 1.3 % overshoot and slow breathing |
| 6.5 s | a light sweep crosses the finished mark |
| 6.9 s | the splash fades out and hands the window to the app |

Click anywhere to skip. Colours are restricted to black, white, grey and blue, exactly as
asked: the only non‑grayscale tokens are `#2f6bff`, `#8db8ff` and the blue bloom.

## The artwork is the real thing

Nothing is typeset. The whale mark, the `deepseek` wordmark, the plate and the `HARNESS`
glyphs are the authentic vectors shipped with the app — extracted from the DeepSeek Harness
asar (`favicon.svg` + `welcome-brand.svg`) into [`dev/logo-data.js`](dev/logo-data.js) by
[`dev/build-logo-data.mjs`](dev/build-logo-data.mjs). That is also why the final frame is
pixel‑identical to the brand row in the app's sidebar.

## Install

```bash
dsh plugin add dsh-boot-splash        # from the marketplace / npm
```

or install the directory straight from a checkout:

```bash
dsh plugin add /path/to/dsh-boot-splash
```

Restart the app (or the `dsh web` process) once — the splash plays on the next boot and then
hands over to the normal UI. It plays **once per page load**; the overlay unmounts itself when
the timeline ends.

## How it is built

* `src/splash.js` — the whole animation: one stylesheet string, one markup block, one pure
  `render(t)` timeline. No framework, no build step at runtime, no global DOM writes outside
  its own subtree.
* `client.js` — generated by `build.mjs` from `src/splash.js` + `dev/logo-data.js`. It mounts
  the animation in a React component registered on the `shell.overlay` slot (a frame‑wide
  floating layer), and tears it down with `ctx.effect`.
* `lib/index.js` — a deliberate no‑op host half, so the loader mounts a fiber and the client
  bundle reaches the page.
* `dev/` — the authoring tools: `boot.html` (freeze any frame with `?t=1200`),
  `shot.mjs` (deterministic frames through the DevTools protocol), `frames.py` (contact
  sheets), `integration.html` (runs the *shipped* `client.js` against tiny stand‑ins for
  `__ModuleLoader__` and React), `make-gif.mjs` + `gif.py` (this README's GIF).

```bash
node build.mjs             # regenerate client.js after editing src/splash.js
node dev/serve.mjs .       # http://127.0.0.1:8899/dev/boot.html?t=2600
node dev/make-gif.mjs      # 78 frozen frames -> python dev/gif.py -> preview/boot-splash.gif
```

## Notes

* The splash is drawn on `shell.overlay`, so it never touches the app root, the sidebar or any
  other plugin's DOM, and it cannot be captured by a scroll container.
* It is purely decorative; there is no host-side behaviour, no settings namespace and no
  network access.
* The brand vectors are DeepSeek's artwork, redistributed here only as part of this fan‑made
  splash; the plugin code itself is MIT.
